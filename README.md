# projeto-ramsomware-dio

🚀 Desafio DIO - Entendendo um Ransomware na Prática com Python<br>
Projeto desenvolvido como parte de um desafio prático da plataforma Digital Innovation One (DIO), com foco em aplicar conceitos teóricos na prática e fortalecer habilidades técnicas.


🎯 Objetivo do Desafio

O objetivo deste projeto foi:<br>

Aplicar os conceitos aprendidos no curso<br>
Desenvolver habilidades práticas em malwares

🛠️ Tecnologias Utilizadas

Python<br>
Linux<br>
Github

📌 Funcionalidades

✅ Criptografa o arquivo de texto com o encrypter.py<br>
✅ Descriptografav o arquivo com o decrypter.py
